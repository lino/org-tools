#+TITLE: org-tools — Installation
#+OPTIONS: toc:2

=org-tools= ships the standalone =org= CLI binary across macOS, Linux (static =musl=), and Windows with zero Emacs or runtime dependencies. Choose the installation method that matches your operating system and workflow.

* Homebrew Tap (macOS & Linux — Recommended)

Install the prebuilt =org= binary, shell completions, and Unix manual pages (=man 1 org=, =man 5 org-tools.toml=) via Homebrew:

#+begin_src sh
brew install --cask lino/tap/org-tools
#+end_src

To upgrade to the latest release:

#+begin_src sh
brew upgrade --cask lino/tap/org-tools
#+end_src

On macOS, the Cask post-install hook clears the =com.apple.quarantine= extended attribute automatically. The unsigned open-source binary runs immediately without Gatekeeper prompts. Operators maintaining the tap can consult [[file:homebrew-tap.org]].

* Container Image (Docker / Podman via GHCR — Zero Local Toolchain)

Run =org= directly from GitHub Container Registry (=ghcr.io/lino/org-tools=) without installing Rust, Emacs, or host packages. Multi-architecture images (=linux/amd64= and =linux/arm64=) publish automatically on =main= and on every =vX.Y.Z= release:

#+begin_src sh
# Pull the latest image
docker pull ghcr.io/lino/org-tools:latest

# Lint and format an Org workspace mounted at /workspace
docker run --rm -v "$PWD:/workspace" ghcr.io/lino/org-tools:latest fmt check .

# Project a multi-day agenda or export a Zensical Markdown report
docker run --rm -v "$PWD:/workspace" ghcr.io/lino/org-tools:latest query agenda /workspace

# Run the stdio MCP server over Docker without a local binary
docker run -i --rm -v "$PWD:/workspace" ghcr.io/lino/org-tools:latest mcp --workspace /workspace
#+end_src

To build the image locally from the repository =Dockerfile=:

#+begin_src sh
docker build -t org-tools:local .
docker run --rm -v "$PWD:/workspace" org-tools:local --version
#+end_src

* Linux System Packages (=.deb= & =.rpm=)

Every [[https://github.com/lino/org-tools/releases][GitHub Release]] publishes static =musl= Linux packages containing =/usr/bin/org=, shell completions, =/usr/share/man/man1/org.1=, =/usr/share/man/man5/org-tools.toml.5=, and license documentation.

** Debian & Ubuntu (=.deb=)

Download the =.deb= package for your CPU architecture (=amd64= or =arm64=) alongside =checksums.txt=. Verify the SHA-256 digest and install with =dpkg=:

#+begin_src sh
# Verify SHA-256 checksum before installing
sha256sum --ignore-missing -c checksums.txt

# x86_64 (amd64)
sudo dpkg -i org-tools_<ver>_linux_amd64.deb

# ARM64 (aarch64)
sudo dpkg -i org-tools_<ver>_linux_arm64.deb
#+end_src

** Fedora, RHEL & openSUSE (=.rpm=)

Download the =.rpm= package for your CPU architecture alongside =checksums.txt=. Verify the SHA-256 digest and install with =rpm= (or =dnf=):

#+begin_src sh
# Verify SHA-256 checksum before installing
sha256sum --ignore-missing -c checksums.txt

# x86_64
sudo rpm -Uvh org-tools-<ver>-1.x86_64.rpm

# ARM64 (aarch64)
sudo rpm -Uvh org-tools-<ver>-1.aarch64.rpm
#+end_src

GoReleaser nFPM may also name RPM assets =org-tools_<ver>_linux_amd64.rpm= or =org-tools_<ver>_linux_arm64.rpm=. Always verify filenames against =checksums.txt=.

* Prebuilt Archives (macOS, Linux & Windows)

Prebuilt release archives bundle =org= (or =org.exe=), =LICENSE=, =README.org=, =completions/=, =man/org.1=, and =man/org-tools.toml.5= for all six targets:

| Platform              | Target Triple                | Archive Asset                         |
|-----------------------+------------------------------+---------------------------------------|
| macOS (Apple Silicon) | =aarch64-apple-darwin=       | =org-tools_<ver>_darwin_arm64.tar.gz= |
| macOS (Intel)         | =x86_64-apple-darwin=        | =org-tools_<ver>_darwin_amd64.tar.gz= |
| Linux (x86_64 musl)   | =x86_64-unknown-linux-musl=  | =org-tools_<ver>_linux_amd64.tar.gz=  |
| Linux (ARM64 musl)    | =aarch64-unknown-linux-musl= | =org-tools_<ver>_linux_arm64.tar.gz=  |
| Windows (x86_64 MSVC) | =x86_64-pc-windows-msvc=     | =org-tools_<ver>_windows_amd64.zip=   |
| Windows (ARM64 MSVC)  | =aarch64-pc-windows-msvc=    | =org-tools_<ver>_windows_arm64.zip=   |

** Verify Checksums & Extract on Linux / macOS

#+begin_src sh
# Verify downloaded archive(s) against checksums.txt (Linux)
sha256sum -c checksums.txt

# Or on macOS when verifying a single downloaded archive
shasum -a 256 --ignore-missing -c checksums.txt

# Extract and place `org` and Unix manpages on your PATH / MANPATH
INSTALL_BIN_DIR="${INSTALL_BIN_DIR:-$HOME/.local/bin}"
INSTALL_MAN_DIR="${INSTALL_MAN_DIR:-$HOME/.local/share/man}"
mkdir -p "$INSTALL_BIN_DIR" "$INSTALL_MAN_DIR/man1" "$INSTALL_MAN_DIR/man5"
tar -xzf org-tools_<ver>_<os>_<arch>.tar.gz
install -m 0755 org "$INSTALL_BIN_DIR/org"
install -m 0644 man/org.1 "$INSTALL_MAN_DIR/man1/org.1"
install -m 0644 man/org-tools.toml.5 "$INSTALL_MAN_DIR/man5/org-tools.toml.5"
#+end_src

If you downloaded a macOS =.tar.gz= in a browser, clear the quarantine attribute before first execution:

#+begin_src sh
xattr -dr com.apple.quarantine "$INSTALL_BIN_DIR/org"
#+end_src

** Verify Checksums & Extract on Windows (PowerShell)

#+begin_src powershell
# Compare SHA-256 hash against checksums.txt
Get-FileHash .\org-tools_<ver>_windows_amd64.zip -Algorithm SHA256
Get-Content .\checksums.txt | Select-String "windows_amd64.zip"

# Extract into a directory on your user PATH
Expand-Archive .\org-tools_<ver>_windows_amd64.zip -DestinationPath "$HOME\bin\org-tools"
#+end_src

* From Crates.io

When =org-tools= is published to crates.io and you have Rust 1.83+ installed:

#+begin_src sh
cargo install org-tools
#+end_src

* From Source (=mise= & Cargo)

Requires Rust 1.83+ (or [[https://mise.jdx.dev/][mise]] to manage the pinned toolchain automatically).

#+begin_src sh
git clone https://github.com/lino/org-tools.git
cd org-tools
cargo install --locked --path crates/org
#+end_src

Or with =mise=:

#+begin_src sh
mise install        # installs pinned Rust toolchain
mise run build      # cargo build
mise run install    # installs `org` into ~/.cargo/bin (override with CARGO_INSTALL_ROOT)
#+end_src

* Shell Completions & Manual Pages

Homebrew Cask and =.deb=/=.rpm= packages install shell completions and Unix =roff= manpages automatically. For source or Cargo installs, generate completions from =org= and copy =man/org.1= and =man/org-tools.toml.5=:

#+begin_src sh
# Bash (user-local completion path)
mkdir -p "${XDG_DATA_HOME:-$HOME/.local/share}/bash-completion/completions"
org --completions bash > "${XDG_DATA_HOME:-$HOME/.local/share}/bash-completion/completions/org"

# Zsh (ensure ~/.zsh/completions is in $fpath before compinit)
mkdir -p "$HOME/.zsh/completions"
org --completions zsh > "$HOME/.zsh/completions/_org"

# Fish
mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}/fish/completions"
org --completions fish > "${XDG_CONFIG_HOME:-$HOME/.config}/fish/completions/org.fish"
#+end_src

* Verify Installation

#+begin_src sh
org --version
org --help
man 1 org
man 5 org-tools.toml
org fmt check --help
org query search --help
org clock report --help
org export ical --help
org update set-state --help
org archive --help
#+end_src
