#+TITLE: org-tools — Release Process

* Pre-release Verification Checklist

1. Run the unified workspace verification gate (=mise run verify=):
   #+begin_src sh
   cargo fmt -- --check
   cargo clippy --all-targets -- -D warnings
   cargo test
   cargo run -- fmt check README.org docs/
   #+end_src
   - [ ] Verify: all four commands exit =0= with zero warnings and zero diagnostics
2. Smoke-test edge-case fixtures:
   #+begin_src sh
   cargo run -- fmt check tests/fixtures/edge_cases/
   #+end_src
   - [ ] Verify: exits =1= (expected fixture diagnostics) with zero panics
3. Preview changelog notes from conventional commits via =git-cliff= (=cliff.toml=):
   #+begin_src sh
   git cliff --config cliff.toml --unreleased
   #+end_src
   - [ ] Verify: conventional commits since the previous =vX.Y.Z= tag are grouped cleanly
4. Validate version synchronization and GoReleaser v2 config in dry-run mode:
   #+begin_src sh
   bash scripts/release.sh --dry-run X.Y.Z
   #+end_src
   - [ ] Verify: =Cargo.toml= and =crates/org/Cargo.toml= sync check passes without modifying files

* Cutting a Release

Use =scripts/release.sh= (or =mise run release X.Y.Z=) to synchronize workspace
manifests, re-run verification checks, create the release commit, tag =vX.Y.Z=,
and push to =origin=:

#+begin_src sh
bash scripts/release.sh X.Y.Z
#+end_src

Passing =--yes= skips the interactive confirmation prompt for automated runs.

* Automated GoReleaser v2 Pipeline

Pushing a =vX.Y.Z= tag (or triggering =workflow_dispatch= for a snapshot dry-run)
runs =.github/workflows/release.yml=:

1. *Validate job*: checks Rust formatting, Clippy lints, full test suite, Org
   documentation formatting, edge-case smoke tests, and tag-to-=Cargo.toml=
   version parity.
2. *GoReleaser v2 multi-arch packaging* (=.goreleaser.yaml=):
   - Builds =aarch64= and =x86_64= release binaries for macOS (Darwin), static
     =musl= Linux (=cargo-zigbuild=), and Windows MSVC (=cargo-xwin=).
   - Generates =bash=, =zsh=, and =fish= completions (=scripts/build-completions.sh=)
     and bundles them into =.tar.gz= / =.zip= archives plus =checksums.txt=.
   - Builds Linux =.deb= and =.rpm= system packages via GoReleaser nFPM.
   - Renders and publishes the =org-tools= Cask to =lino/homebrew-tap= when
     =HOMEBREW_TAP_GITHUB_TOKEN= is configured (see
     [[file:homebrew-tap.org][Homebrew Tap Operations]] and
     [[file:installation.org][Installation Guide]]).
   - Verifies all release artifacts and emits Prometheus / JSONL telemetry via
     =scripts/verify-release-packages.sh=.
3. *Optional =crates.io= publish gate*:
   - When =CARGO_REGISTRY_TOKEN= is configured on a =v*= tag push, publishes
     =org-tools-core= followed by =org-tools=.
   - When =CARGO_REGISTRY_TOKEN= is unset (or during snapshot =workflow_dispatch=
     runs), the job logs a GitHub Actions notice and exits =0= cleanly without
     blocking GitHub Releases or Homebrew tap updates.
4. *GHCR multi-arch container publish* (=publish-container= job):
   - Builds the multi-stage =Dockerfile= for =linux/amd64= and =linux/arm64= via
     Docker Buildx and pushes =ghcr.io/lino/org-tools:<version>=,
     =:<major>.<minor>=, =:<major>=, and =:latest= using =GITHUB_TOKEN=
     (=packages: write=).
   - Snapshot =workflow_dispatch= runs verify the multi-arch Buildx build
     without pushing tags to =ghcr.io=.

* Post-release Checklist

- [ ] Verify GitHub Actions =Release= workflow succeeded and uploaded =release-telemetry=
- [ ] Verify GitHub Release page lists multi-OS archives, =.deb= / =.rpm= packages, and =checksums.txt=
- [ ] Verify =docker run --rm ghcr.io/lino/org-tools:vX.Y.Z --version= resolves the published multi-arch GHCR image
- [ ] Verify =brew install --cask lino/tap/org-tools= installs =vX.Y.Z= when tap publishing is enabled
- [ ] Verify =crates.io= shows =vX.Y.Z= if =CARGO_REGISTRY_TOKEN= is configured
